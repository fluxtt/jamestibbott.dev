# jamestibbott.dev

A small personal website that exists for one reason:  
**to be a playground for fun, interesting, and occasionally strange web experiments.**

This site is _not_ a portfolio, _not_ a CV, and _not_ trying to impress anyone.  
It’s simply a place where I build things I enjoy — and if someone stumbles across it and finds something cool, that’s a bonus.

## 🧭 Structure

- **Homepage** — landing page
- **Projects** — larger experiments
- **Utilities** — tiny tools
- **Misc** — anything that doesn’t fit anywhere else

## 🛠 Tech

Mostly simple HTML/CSS/JS with occasional PHP where needed.  
The goal is to keep things lightweight and easy to extend.

## 🎯 Purpose

To have a personal corner of the internet that evolves over time —  
a digital playground rather than a professional showcase.
